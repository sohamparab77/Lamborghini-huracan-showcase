## 📕 Repository Structure
```text
lamborghini-huracan-showcase/
├── assets/              # High-res car images, SVGs, logos, and showcase video
├── index.html           # Main landing page markup
├── style.css            # Custom layout, styling, and animations
└── script.js            # Frontend interactivity and scroll behaviors
```
## ⚙️ Local Setup

**1. Clone the repository:**
```bash
git clone https://github.com/sohamparab77/lamborghini-huracan-showcase.git
```

**2. Navigate to the project**
```bash
cd lamborghini-huracan-showcase
```

**3. Open the project**
```text
Open index.html directly in your browser, or use a live server extension (like VS Code's Live Server) for the best development experience.
```
